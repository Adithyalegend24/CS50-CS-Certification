## 📌 About CS50x

**CS50x — Introduction to Computer Science** is Harvard University's introductory computer science course. It develops problem-solving and computational thinking skills through programming, algorithms, data structures, databases, AI, and web development.

The course covers multiple technologies including **C, Python, SQL, HTML, CSS, JavaScript, and Flask**.

# 🎮 Final Project — Aether Storm

## 🚀 Overview

**Aether Storm** is my CS50x Final Project — a **browser-based 2D space survival game**.

The player controls a neon spaceship, fights increasingly difficult enemy waves, collects power-ups, and attempts to achieve the highest possible score.

The project combines programming, algorithms, real-time rendering, audio, user interaction, and modular JavaScript development.

---

## 🕹️ Gameplay

| Feature     | Description                                         |
| ----------- | --------------------------------------------------- |
| 🚀 Player   | Control a neon spaceship                            |
| 🎯 Combat   | Aim with mouse and fire plasma projectiles          |
| 👾 Enemies  | Drones, Strikers, Tanks, Splitters and Void Reapers |
| 👑 Bosses   | Void Reapers appear every fifth wave                |
| ⚡ Power-Ups | Rapid Fire, Energy Shield, Repair Kit, Spread Shot  |
| 🌊 Waves    | Increasing difficulty as waves progress             |
| 💯 Scoring  | Destroy enemies and survive to achieve a high score |

### Controls

| Action | Key                   |
| ------ | --------------------- |
| Move   | `WASD` / Arrow Keys   |
| Aim    | Mouse                 |
| Fire   | Mouse Click / `Space` |
| Pause  | `P` / `Escape`        |

---

## 🔄 Game Architecture

```text
Input
  ↓
Game State
  ↓
Update Entities
  ↓
Collision Detection
  ↓
Wave & Score Update
  ↓
Render Canvas
  ↓
Next Frame
```

The game continuously updates the player, enemies, projectiles, power-ups, particles, collisions, waves, and HUD before rendering the next frame.
